# Solo Tracker

**为独立工作者设计的多项目可视化工具 — 看板 + 甘特图，打开即用。**

> 由 [Clora Chen](https://github.com/clorachen) 构建 — 一个厌倦了为用不到的功能付费的 PhD 研究者和 AI 创业者。

---

## 为什么做 Solo Tracker？

市面上大多数项目管理工具是为团队设计的，里面塞满了协作功能、权限系统、复杂的配置流程——但如果你是一个人在跑项目，这些都是噪音。

Solo Tracker 只做一件事：**让你随时能看清所有项目的全局进度**，没有多余的东西。

- **看板视图** — 拖拽任务改变状态，所有项目一屏滚动看完
- **甘特图** — 月/周/天三档视角，直接拖拽调整任务时间
- **打开即用** — 下载文件，浏览器打开，直接开始。无需注册，无需配置
- **数据完全本地** — 所有数据存在你自己的浏览器里，不上传任何服务器

---

## 适合谁用？

Solo Tracker 专为同时管理多个项目的独立工作者设计：

- AI 创业者 / Indie Hacker（同时验证多个方向）
- PhD 学生和研究者（论文、实验、投稿并行推进）
- 自由职业者（多客户并行）
- 内容创作者（多平台、多选题同时推进）
- 副业党（主业之外有 2-3 条项目线）

## 功能列表

| 功能 | 说明 |
|---|---|
| 多项目看板 | 每个项目独立泳道，行对齐网格布局 |
| 甘特图 | 月/周/天视角切换，今天红线，任务条可拖拽 |
| 任务状态 | 待办 → 进行中 → 待验证 → 已完成 |
| 优先级标签 | P0/P1/P2/P3，颜色区分 |
| 时间自动记录 | 自动记录任务进入每个状态的时间 |
| 已完成时间轴 | 显示计划时间、实际完成时间、历时天数 |
| 拖拽排序 | 任务行和项目顺序均可拖拽调整 |
| 项目名内联编辑 | 点击项目名直接编辑，无需弹窗 |
| 泳道折叠 | 暂时不关注的项目可以折叠隐藏 |
| 本地持久化 | 数据存在 localStorage，关闭浏览器/电脑重启不丢失 |
| 深色模式 | 跟随系统自动切换 |
| 零依赖 | 单个 HTML 文件，无需构建工具，无需框架 |
